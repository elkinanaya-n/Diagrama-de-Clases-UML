# Checklist de entrega

- [ ] Repositorio GitHub creado con nombre descriptivo.
- [ ] Todos los integrantes agregados como colaboradores.
- [ ] Cada integrante tiene al menos un commit propio.
- [ ] Proyecto Java compila y ejecuta `main.Main`.
- [ ] README actualizado.
- [ ] Evidencias de ejecución incluidas.
- [ ] Video de 5 a 8 minutos grabado.
- [ ] Permiso de visualización del video verificado por el docente.
- [ ] Repositorio público o acceso del docente configurado.
- [ ] Informe PDF en formato APA 7 revisado.
- [ ] Enlace al repositorio y enlace al video colocados después de las conclusiones.
